Method

Items

CBP "Classification" rulings from 2026 that cite exactly one 10-digit code; that code is the answer. Dev: January to May 2026, used for tuning. Test: from 1 June 2026, after the post-training cutoff of Nemotron 3 Ultra and 3.5 Lightning (May 2026, per NVIDIA's model cards), run once. Dev is after their September 2025 pre-training cutoff.

No leakage

Every system sees the same product description with all tariff numbers, chapter references and ruling numbers removed. Precedent search returns only rulings issued before the split starts, and never the ruling itself or one it cites. A test checks every input for its own answer.

Systems

Keyword match; Nemotron 3.5 Lightning and Nemotron 3 Ultra asked for a code; the closest retrieved ruling's code; the Proposer alone (Ultra choosing among retrieved rulings); the Proposer kept only when its own stated confidence is high enough to answer as often as the gate does; the Proposer filtered by Zetaris liveness; and the gate, which adds the Critic. The last four come from the same calls on the same items, so each difference is one layer.

Metrics

Coverage is the share of items a system answers. Accuracy counts exact 10-digit matches on answered items, with 95% Wilson intervals. Stale-code rate is the share of answers whose code is not in HTS 2026 Rev 21, checked against the Zetaris schedule.
