For judges

Check every claim yourself, in about five minutes.

No keys, no Zetaris and no Nightshift needed: sample mode replays the recorded responses of those services and runs the gate's own logic on them. Live mode needs all three.

From a fresh clone

Install

Python 3.12. No other system dependency.

git clone https://github.com/Cassxbt/portorium && cd portorium
python3.12 -m venv .venv && . .venv/bin/activate
pip install -e '.[dev]'

Run the tests

Gate rules, liveness, the Critic, traces, recorder replay, evaluation leakage and resume.

pytest -q

Meterless H-MEM conformance

The official H-MEM test vectors against the Python port, and a mutation test showing the vectors catch a broken port.

pytest tests/test_hmem_conformance.py -v

Classify in sample mode

The recorded demo inputs replay exactly. Each prints its precedents, Zetaris status, receipts and the trace file it wrote.

SAMPLE_MODE=true portorium classify "Women's V-neck pullover, 100% cotton jersey knit fabric, long sleeves, hemmed bottom"
SAMPLE_MODE=true portorium classify "Men's knitted polo shirt with short sleeves and a three-button placket"

Open the console and this site

Same code, served locally.

SAMPLE_MODE=true uvicorn portorium.web:app --port 8781
# http://127.0.0.1:8781

Read a trace

One JSON line per step: role, handoff, model, retries, status. Written as the run happens, never edited.

ls logs/ && head -3 logs/trace-*.jsonl

Check the test set was run once

The lock records the test file's hash, the commit and the prompt hash at the start of the only test run.

cat data/eval/TEST_RUN.lock
shasum -a 256 data/eval/test.jsonl
Claim → where to check
ClaimEvidence
A model may suggest a code but never gives oneportorium/gate.py: the Proposer's code must be cited by a retrieved, standing ruling; decide is plain rules; the Critic can only send a case to review. Trace lines show which role produced what.
Zetaris decides whether a precedent is alivescripts/zetaris_usl.sql registers code_in_schedule and parent_survives; portorium/liveness.py cross-checks against their invalid records and queries per request.
A living code is also checked against its current textliveness.schedule_text builds the Rev 21 path and alternatives in Zetaris SQL; the Critic's verdict is in each trace.
Every reasoning call goes through Nightshift and names its modelportorium/nightshift.py; every chat line in a trace carries routed_model and a receipt id.
Embed and Rerank are the only direct NVIDIA callsportorium/nvidia.py; on Nightshift M1–M4 0.92.3, POST /v1/embeddings answers 501 route_not_implemented ("not served in the web build"), re-checked on 26 October.
Broker memory is Meterless H-MEMportorium/engines/hmem.py, portorium/memory.py, the conformance test above.
No evaluation input reveals its answerportorium/leakage.py; pytest tests/test_eval_inputs.py checks every dev and test item.
Evaluation numbers come from the run filesThe site reads them through /api/eval from data/eval/results/; the README tables are generated by scripts/eval_table.py.
Sample mode is the real gate on recorded dataportorium/recorder.py replays service responses by request hash; scripts/build_sample.py made them in one live walkthrough.
