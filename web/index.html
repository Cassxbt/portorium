No code without a living precedent.

Portorium gives an import a tariff code only when a prior US Customs ruling cites it, that ruling still stands, the code still exists in today's schedule, and the product fits the code's current wording. Otherwise it asks the importer one question, or refuses.

The failure

Tariff codes die. Models keep using them.

The 2026 US tariff schedule is already on its 21st revision. Codes are split, renumbered and deleted, and old rulings are revoked. A code recalled by a model, or copied from a past ruling, can name a line that no longer exists.

Built on

Zetaris

Holds the schedule and the rulings as one virtual layer. Its data-quality rules decide whether a precedent is alive, it returns each code's current wording for the Critic, and every verdict is written back and re-screened.

Meterless

Nightshift routes every reasoning call and returns a receipt naming the model that ran. H-MEM keeps broker sign-offs and importer answers, with a deletion ledger.

NVIDIA Nemotron

Embed and Rerank find the precedents. Nemotron 3 Ultra compares them, proposes a code and checks it against the schedule's wording. Lightning serves as an evaluation baseline.
