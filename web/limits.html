Limits

Where it stops, and why.

A classifier that refuses is only useful if it is honest about how often, and about what it cannot see.

  1. It answers a minority of products

    On the evaluation it classifies only part of the products on its own; the rest go to one question or to a broker. That is the design, and it is also the cost.

  2. It advises; a broker decides

    A tariff code on an entry is the importer's legal declaration. Portorium proposes and explains; a licensed customs broker signs off, and the sign-off is what it remembers.

  3. US rulings only

    Precedents are CBP rulings from the CROSS database. Other customs authorities' rulings, court decisions and Explanatory Notes are not consulted.

  4. One schedule revision at a time

    Liveness is checked against HTS 2026 Revision 21 as loaded into Zetaris. A rule flags when USITC publishes a newer release; loading it is a manual step.

  5. The models can be wrong

    Which cited code applies, and whether a product fits a line's wording, are model judgements. The Critic misses some wrong codes and rejects some right ones; the evaluation counts both, and the trace shows each judgement so a broker can overrule it.

  6. Product facts come from ruling text

    Each precedent's description is cut from the ruling between the salutation and the legal analysis, with sentences naming people removed. Rulings without clear facts count as weaker evidence.

  7. Small samples, wide intervals

    The evaluation uses 2026 rulings that cite exactly one code, and CBP's code as the answer. At these sizes the 95% intervals are wide; read them before reading the point estimates.

  8. Retrieval calls NVIDIA directly

    The Nightshift M1–M4 build has no embeddings route, so Nemotron Embed and Rerank use NVIDIA's API with the same key. Every reasoning call goes through Nightshift.

  9. Sample mode covers the recorded walkthrough

    Without services, only the recorded demo inputs replay. Any other product needs live mode: NVIDIA, Nightshift and Zetaris.
