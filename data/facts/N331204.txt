The merchandise under consideration is a Remote Start System Kit (Kit), Model APS901TM, which is designed for use with vehicles. The subject kit consists of two remote-control fobs, a remote start module, two wire harnesses, an antenna, an antenna harness, a pin switch, and an installation guide. After installation, one can unlock/lock doors and remote start the vehicle from the radio remote control fobs. Based on the information provided, the remote start feature can start a vehicle from 1,500 feet away. This kit performs a clearly defined function of radio remote control apparatus.
