The merchandise under consideration is identified as the Tempering Beam Walking Furnace Control System, the Tempering Furnace Grease Control System, the Descaler Unit Control System, and the Tempering Furnace Hydraulic Unit Control System. Each of the control panels are said to be components of the operator interface of a rolling mill and operate at less than 1,000 V. The Tempering Beam Walking Furnace Control System is an operator control station that is comprised of illuminated pushbutton switches, selector switches, keylock switches, contact blocks, joystick controllers, and status indicators which are installed in a pedestal mounted steel enclosure. The Tempering Beam Walking Furnace Control System provides for the local and/or remote electrical control and the start and stop functions for the rolling mill walking beam functions of the rolling mill. The Tempering Furnace Grease Control System is an operator control station that is comprised of illuminated pushbutton switches, selector switches, indicators, and contact blocks mounted in a steel enclosure. The Tempering Furnace Grease Control System provides for the local and/or remote electrical control of and the start and stop functions for the grease unit of the rolling mill. The Descaler Unit Control System is an operator control station that is comprised of illuminated pushbutton switches, selector switches, indicators, and contact blocks mounted in a steel enclosure. The Descaler Unit Control System provides for the local and/or remote electrical control of and the start and stop functions for the descaler pumps and discharging valve of the rolling mill. The Tempering Furnace Hydraulic Unit Control System is an operator control station that is comprised of illuminated pushbutton switches, keylock switches, and selector switches, indicators, and contact blocks mounted in a steel enclosure. The Tempering Furnace Hydraulic Unit Control System provides for the local and/or remote electrical control of and the start and stop functions for the main and recirulation hydraulic pumps of the rolling mill.
