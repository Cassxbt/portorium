The merchandise in question is the VIPER 3308V LCD 2-Way Security System, which is imported as a set  consisting of two remote controls (key fobs), harnesses, a control module, and a siren. The remote control  key fobs include a 2-Way LCD command-confirming transmitter and a 1-Way 4-button transmitter, controll  ed via radio frequency (RF) up to a 1/4-mile range. The 2-Way LCD command-confirming transmitter is a  radio remote control key fob with an LCD screen that provides visual confirmation of the system and control  buttons for locking, unlocking, arming, disarming, auxiliary channel, and panic activation. The 1-Way  4-button transmitter is also a radio remote control key fob that contains control buttons for locking,  unlocking, arming, disarming, an auxiliary channel, and panic activation.
