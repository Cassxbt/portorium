The merchandise under consideration is referred to as the Smart Monitor Display Unit (SDU), PN RD-FW8800-51, which is described as a 24” LCD display monitor with a resistive touch overlay that is installed into the back of passenger seats on an aircraft for the purpose of providing the end user with an interface to the automatic data processing (ADP) network. Based on the information provided, end users interact with the various applications stored on the networked server where a multitude of applications and media files are stored. The SDU is said to perform a number of basic functions such as web browsing, interaction with installed applications, playing games, and video/audio entertainment which are some of the examples provided in your request. We would note that the subject display unit does not contain a tuner or channel selector and is designed to directly interface with the server.
