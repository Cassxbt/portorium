The item concerned is referred to as the Synergis Cloud Link G2, model SY-CLOUDLINK-G2. This item is  a gateway device which functions as an add-on to an existing access control infrastructure. It allows  cloud-based access and secured communications. Specifically, this device performs a data  transmission/reception function within a network, while remaining independent of the access control system  server. The function of this gateway device is to link existing on-premises hardware, like controllers, modules, and  electronic locks, to the cloud, and provides authenticated communication between hardware and the cloud. This device can support up to 256 readers and electronic locks and monitor hundreds of zones and alarms. Th  is gateway device is necessary for the transmission/reception of data, it is not a network security device, nor   does it make routing or switching decisions.
