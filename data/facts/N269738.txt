The item concerned is referred to as a Flow Detector Harness Assembly, Part # 0140-09664. It consists of a magnetic rotor and coil assembly in a stainless steel housing. It incorporates an electronics package, an internal relay and a wiring harness. The housing has a clear plastic faceplate that allows the rotor to be viewed for a visual indication as to whether or not fluid is flowing. Fluid flowing through the flow detector rotates the magnetic rotor, which induces a voltage in the coil. The electronics package compares this voltage against a user assigned set point (voltage). When the voltage is above the set point the relay is energized. This indicates that fluid is flowing as expected. If the voltage falls below the set point or if fluid stops flowing, power to the relay is shut off and the relay is de-energized. This indicates that fluid is not flowing as expected which means there may be a problem. This change of state of the relay is interpreted by a user supplied interface which is then used to control other system functions.
