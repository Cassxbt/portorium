The items concerned are control box housings used on noise canceling aviation headsets. The housings are  made from ABS-PC, which is a thermoplastic blend of polycarbonate (PC) and  acrylonitrile-butadiene-styrene (ABS). When installed, the housings (with internal electrical components),  are situated on the audio/power cable of the headset between the headset itself and the audio plug which is  used to connect to the aircrafts console. These control box housings will eventually incorporate the PCBAs,  switches, etc., used for the control/processing functions of the headsets. The first set of control box housings is used specifically with the Delta Zulu Aviation Headsets:  The first item concerned is referred to as part # 303-00208-000.B3 – PCB, Module, Top. This is the  top portion of the control box housing for the Delta Zulu Aviation Headset. The second item is referred to as part # 303-00209-000.B4 PCB, Module, Bottom. This is the bottom  portion of the control box housing for the Delta Zulu Aviation Headset. The second set of control box housings are used specifically with the Zulu 3 Aviation Headsets:  The first item concerned is referred to as part # 250-00055-000.A1 Assy, Battery Box, Bottom. This  is the bottom portion of the control box housing, which is used with the battery powered version of  the Zulu 3 Aviation Headsets. The second item concerned is referred to as part # 250-00056-000.A3 Control Box Bottom, Panel  Power. This is the bottom portion of the control box housing, which is used with the panel powered  version of the Zulu 3 Aviation Headsets. The third item concerned is referred to as part # 303-00197-000.A2 Control Box, Top. This is the top  portion of the control box housing, which is used with the Zulu 3 Aviation Headsets.
