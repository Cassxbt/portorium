The merchandise under consideration it the LG Cloud V-series box, model number CBV42-B (Zero Client TERA2). This box, which contains Teradici PCoIP technology, receives and decodes encrypted image information from a server and transmits it to a monitor. Moreover, this data reception, conversion, transmission box helps create a virtual work environment. The V-series box can be mounted on the back of a monitor, but does not contain an operating system, a CPU, a tuner, or any storage capability.
