The merchandise under consideration is identified as the Tempering Furnace Area Main Control Desk, the Tempering Furnace Combustion Fan Control System, the Tempering Furnace Recirculation Fan Control System, the Tempering Furnace Entry Side Control System, and the Tempering Furnace Exit Side Control System. Each of the control panels are said to be components of the operator interface of a rolling mill and operate at less than 1,000 V. The Tempering Furnace Area Main Control Desk is an operator control station that is comprised of pushbutton switches, circuit breakers, contact blocks, status indicators, keyboards, and cutouts for two human machine interface modules. The Tempering Furnace Area Main Control Desk communicates with the automation supervisory controller for the rolling mill operation via an onboard interface module and allows for the electrical control and monitoring of certain processes. The Tempering Furnace Combustion Fan Control System is an operator control station that is comprised of illuminated pushbutton and selector switches and contact blocks mounted in a steel enclosure. The Tempering Furnace Combustion Fan Control System provides for the local and/or remote electrical control of the start and stop functions for the furnace fans. The Tempering Furnace Recirculation Fan Control System is an operator control station that is comprised of illuminated pushbutton and selector switches and contact blocks mounted in a steel enclosure. There are four fans which are controlled with a start and stop pushbutton switch for each fan. The Tempering Furnace Recirculation Fan Control System provides for the local and/or remote electrical control of the start and stop functions for the furnace fans. The Tempering Furnace Entry Side Control System is an operator control station that is comprised of illuminated pushbutton, selector, and keylock switches, contact blocks, joystick controllers, and status indicators which are installed in a pedestal mounted steel enclosure. The Tempering Furnace Entry Side Control System provides for the local and/or remote electrical control and the start and stop functions for the charging equipment and walking beam functions of the rolling mill. The Tempering Furnace Exit Side Control System is an operator control station that is comprised of illuminated pushbutton, selector, and keylock switches, contact blocks, joystick controllers, and status indicators which are installed in a pedestal mounted steel enclosure. The Tempering Furnace Exit Side Control System provides for the local and/or remote electrical control and the start and stop functions for the discharging equipment and walking beam functions of the rolling mill.
